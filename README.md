# Crazy Games BH — launch set (Instagram)

Rebuild: `python3 render.py` (renders `src/*.html` → `out/*.jpg` + contact sheets). `python3 build.py` regenerates the HTML from the system if copy/layout changes. Swap higher-res PNGs into `games/` with the same filenames and re-run `render.py`.

Every design carries the logo (top right) and a small English label (top left). Digits are Latin; currency is «د.ب».
